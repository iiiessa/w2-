Vortex Store Welcome Bot

1) Install Node.js (LTS).
2) Open this folder in Terminal / PowerShell.
3) Run: npm install
4) Set environment variables:
   DISCORD_TOKEN = your Discord bot token
   WELCOME_CHANNEL_ID = the ID of your #welcome channel
5) Run: npm start

Discord Developer Portal:
- Bot -> Privileged Gateway Intents -> enable Server Members Intent.
- Do NOT share your bot token.

The bot sends a welcome image when a member joins. The member's Discord avatar is placed in the circle on the right.
